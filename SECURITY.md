# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest commit
on `main` only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting feature for this repository. Include affected
versions, reproduction steps, impact, and any proposed mitigation.

The maintainers will acknowledge a report within seven days and will coordinate
disclosure after a fix is available.
